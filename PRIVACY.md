# Privacy Policy

LoL Esports Schedule does not collect, store, or transmit any personal information.

The extension:
- Retrieves public match schedules from Riot Games' LoL Esports API.
- Retrieves public live status information from Twitch for the optional Caedrel LIVE badge.
- Stores a single preference (`notifyLive`) locally using Chrome's storage API to remember whether the LIVE badge is enabled.

No user data is sent to the developer or any third party beyond the requests necessary to retrieve public schedule and Twitch status information.

The extension does not use analytics, advertising, tracking technologies, or cookies.
